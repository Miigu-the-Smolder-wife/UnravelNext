# 렌더러 결함 큐 (2026-10-01, 조정 세션)

사용자 지시(2026-10-01 12시): 잡음은 두 세션이 하나씩 맡는다. GI 얼룩은 R(`UnravelNext-redesign`, 브랜치 `redesign-v2`)이 맡는다. 반사·차폐 잡음은 S2(`UnravelNext-refl`, 브랜치 `redesign-v2-refl`)가 맡는다. 남은 렌더러 결함은 빨리 고친다. 어느 세션이든 하던 일이 끝나면 이 큐에서 다음 결함을 맡는다.

## 맡는 법

- 위에서부터, 맡은 세션 칸이 비어 있는 첫 행을 맡는다.
- 맡은 세션 칸에 세션 이름(R, S2, A, B)과 시각을 적는다. 이 파일만 경로 지정 커밋으로 main에 커밋·푸시한다(`C:\Users\USER\UnravelNext`에서). 같은 행을 두 세션이 잡지 않게 하려는 것이다. 푸시가 충돌하면 pull한 뒤 다시 본다. main에 커밋하지 않는 세션(R)은 조정 세션에 메시지로 알리고, 표시는 조정 세션이 한다.
- 고치는 곳은 자기 브랜치다. 커밋 sha와 실측 결과를 상태 칸에 적고, 조정 세션에 send_message로 알린다(세션 id `local_a166ac48-2eb7-45aa-8383-b09b94d15180`).
- 완료 판정은 조정 세션이 한다. 게임 화면에 들어가는 것은 조정 세션의 배포(게임 핫픽스 또는 redesign 배포) 뒤다.
- 규칙은 세션 프롬프트와 같다: 품질·표본·부하를 낮추지 않는다. 회피 구현은 금지다. 수치에는 [실측]/[예상]을 붙인다. 기존 경로는 A/B 스위치로 남긴다. 작업량을 바꾸는 변경은 커밋 전에 timing을 1회 잰다. GPU 잠금 종류는 정확성이면 correctness, 시간 측정이면 timing이다.
