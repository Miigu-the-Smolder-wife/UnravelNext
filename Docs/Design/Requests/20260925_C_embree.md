# 요청: Embree 4.4.1을 `Unx::Embree`로 고정 (C 트랙, 2026-09-25)

## 필요한 이유
C 트랙의 CPU 기준 경로추적기(INTERFACES 10.2)는 Embree로 광선을 추적한다(REBUILD_PLAN 14.1-4). INTERFACES 2.3에 따라
새 외부 라이브러리는 코어가 `External/Dependencies.cmake`에 고정해 `Unx::<이름>`으로 내보낸다.

## 원하는 변경 (코어 소유 파일: `External/Dependencies.cmake`)
- 공식 배포본: https://github.com/RenderKit/embree/releases/download/v4.4.1/embree-4.4.1.x64.windows.zip
- SHA-256: `5aa1fa3161a720f9c610b06c652b80f421cb2b1fe8221fdf92b74157336fdf8f` (GitHub 릴리스가 공개한 digest와 내려받은 파일이 일치함을 확인)
- 라이선스: Embree Apache-2.0, 동봉된 oneTBB(`tbb12.dll`, `tbbmalloc.dll`) Apache-2.0.
- 내보낼 것: `Unx::Embree` (IMPORTED SHARED, include `include/`, 라이브러리 `lib/embree4.lib`, DLL `bin/embree4.dll`) 와 실행 폴더에 `embree4.dll`, `tbb12.dll`, `tbbmalloc.dll`을 복사하는 함수(`unx_deploy_embree(target)`).

## 그때까지의 처리 (공유 파일은 고치지 않음)
`Reference/CMakeLists.txt`(C 소유)가 `if(NOT TARGET Unx::Embree)`일 때만 같은 URL·같은 SHA-256으로 `build/<트랙>/_deps/`에
받아 같은 이름의 타깃을 만든다. 코어가 `Unx::Embree`를 정의하면 그 블록은 건너뛰고 코어 정의를 쓴다. 다른 트랙에는 영향이 없다.

## 영향
- C 트랙 타깃(`unx_reference`, `unx_test_reference`)만 링크한다. 렌더러 모듈은 Embree에 의존하지 않는다.
