# 요청: 수면 기하를 V 메시 셰이더에서 변위하는 패치 스트림 (W → V) — 2026-09-26

B7 수면의 기하 규칙을 FEATURES_GAME 1("변위는 메시 셰이더에서")이 정하지 않았다. 그래서 정보량에서 규칙을 세우고, V에 형식을 요청한다. 저장 삼각형 스트림(v1.60, 1d5f10e)은 유체 표면(B8)에 그대로 쓴다. 이 요청은 수면만 다룬다.

## 1. 기하가 담아야 하는 정보 — 격자 간격 규칙

- 수면 = FFT 3 캐스케이드의 변위 P(x, z, t) = (x + Dx, h, z + Dz). 필드와 밉은 W가 매 프레임 만든다(Ocean.h, f524cd0).
- 정점 간격 Δ인 격자는 파장 2Δ보다 긴 대역만 그린다. 짧은 대역은 픽셀 셰이딩의 법선(기울기 밉)에만 남는다. 그 짧은 대역의 변위 RMS를 σ(Δ)라 하자. σ(Δ)는 스펙트럼에서 정확히 구한다: σ(Δ)² = Σ_{|k| > π/Δ} E(k) dk². W가 해상태마다 호스트에서 표로 만든다.
- **품질 규칙**: 그려진 면과 대역 제한 FFT 면의 위치 차가 모든 거리에서 0.5 px 이하여야 한다(최대값 기준 3σ). 거리 d에서 픽셀 각 θ_px이면 조건은 3σ(Δ) ≤ 0.5 d θ_px이고, 이를 만족하는 가장 큰 Δ(d)를 쓴다.
- 포화 꼬리(α ≈ 0.01, JONSWAP)에서는 σ(Δ) = c_s Δ, c_s = √α / (2π) ≈ 0.016이다. 그래서 Δ = r d, r = θ_px / (6 c_s)가 된다. 4K 60° FOV에서 θ_px = 4.8e-4 → r = 0.005이고, 삼각형은 화면에서 가로 약 10 px다.
- σ(Δ)가 전체 RMS σ_tot에서 포화하는 거리(d ≥ 6 σ_tot / θ_px) 너머는 어떤 간격도 조건을 만족한다. 잔잔한 호수(σ_tot 2 cm)는 250 m 너머가 평면 + 법선이다.

## 2. 삼각형 수 식 (4K) — 정확 기하만으로는 불가능하다 (정정)

- 세계 고정 CDLOD 사분 트리를 가정한다. 패치는 8×8 사각형(128 삼각형)이고, 이웃 LOD와는 정점 모핑으로 잇는다.
- 처음 보낸 2.2 M은 세 가지를 빠뜨렸다.
  - 변위는 벡터다. |D̂| = |ĥ|이므로 σ_P = √2 σ_h다.
  - 틈 없는 모핑에는 여유 κ가 필요하다. 문턱 D_L = max(κ d*(L), 2 D_{L−1}), κ = 1.25다.
  - 사분 트리 간격은 요구 간격의 1/2~1배다.
- 정정하면 r_eff ≈ 1/353~1/706이고, 옥타브당 약 0.69 M 삼각형이다. 열린 바다(12옥타브)는 **약 7 M** [예상]이다.
- 렌더 C 실측(unx_gate_visibility_streamgate, 4K, 수평선까지 약 10 px 삼각형):
  - 1.09 M 삼각형 = 스트림 래스터 2.30 ms + coverage 정리 3.20 ms로, 약 5.5 ms다.
  - 단가는 삼각형당 약 1.5 ns + 기록당 0.31 ns다.
  - 정확 기하 7 M은 10 ms가 넘는다. 기하로 정보를 담는 방식은 예산과 두 자릿수가 벌어진다.

## 2b. 재설계: 거친 경계 메시 + 픽셀별 정확 교점

- 픽셀에 필요한 정보는 시선과 대역 제한 FFT 면의 **교점 하나**(위치·깊이·휴지 좌표)다. 격자 해상도는 이 정보가 아니다.
- **거친 경계 메시**: 패치 삼각형을 화면 약 16~32 px로 둔다. 삼각형 수 N ≈ 수면 픽셀 / 128~512 × LOD 계수로, 열린 바다 4K에서 약 0.05~0.15 M이다. 이 메시를 정점마다 σ(Δ) 경계만큼 **위로 올린 상한 껍질**로 그린다. 그러면 참 면에 닿는 모든 시선이 이 메시 픽셀 안에 들어온다(보수적 커버리지).
- **픽셀별 교점 정제**(물 층 픽셀 셰이더, W 함수 `oceanRefine`): 껍질 교점에서 시작한다. 휴지 좌표 x₀를 고정점 반복으로 구한다: x₀ ← x_ray(t) − D(x₀). 높이 조건 h(x₀) = y_ray(t)는 할선법으로 t에 대해 푼다. 각 반복은 캐스케이드 3개의 변위 표본이다. 수렴하면 SV_Depth로 정확 깊이를 쓰고, 시선이 면을 지나치면(마루 사이로 빠짐) 픽셀을 버린다. 그러면 실루엣도 픽셀 단위로 정확하다. 가장자리 부표본 면적은 C 제안대로 M/E 합성이 맡는다.
- **비용** [예상]: 거친 메시 0.1 M × 1.5 ns = 0.15 ms. 정제는 수면 픽셀 P_w × 반복 k(4) × 캐스케이드 3 × 표본 2(변위·기울기)이고, 텍스처 표본 약 300 G/s 기준으로 P_w = 8.3 M(화면 전체 물)이면 약 0.66 ms, 수변 1.66 M이면 약 0.13 ms다.
- **정확 조건**: 정제가 수렴한 픽셀은 대역 제한 FFT 면과의 교점과 같다(반복 허용 오차 ≤ 0.05 px). 수렴하지 않은 픽셀 수를 게이트에서 세고 0이어야 한다. 반복 k의 최악 dispatch 한도는 구조적 상수(k 고정)다.
- 이 방식이면 기하 간격 규칙(1절)은 껍질의 두께 경계에만 쓰인다. 정확성은 픽셀 정제가 진다.

## 3. V에 필요한 것 (이름은 V가 정한다)

렌더 C 제안(2026-09-26)과 합친다: 물 전용 층(band A 깊이 복사본에 하드웨어 1표본 래스터, 픽셀마다 물 id + 깊이 1겹, band A 수중 장면 보존). 이 층의 픽셀 셰이더가 W의 `oceanRefine`을 불러 SV_Depth를 쓰거나 픽셀을 버린다(2b).

1. **패치 스트림 형식**: FrameResources에 (패치 버퍼, 패치 수 인자 = DispatchMesh 간접 인자, 재질, 인스턴스, bounds)를 둔다. 패치 1개 = 메시 셰이더 그룹 1개 = 128 삼각형이다. 삼각형 id = 패치 × 128 + 패치 안 색인으로, 지금의 24비트 삼각형 비트에 들어간다(패치 ≤ 131 k).
2. **변위 함수**: V의 메시 셰이더가 W의 include(`Passes/Water/OceanPatch.hlsli`, W 소유)를 부른다. 함수는 `oceanPatchVertex(patch, i, j) → 월드 위치, 이전 프레임 월드 위치`이다. 법선은 셰이딩 시점에 M이 같은 include의 `oceanNormal(x, z, footprint)`로 픽셀마다 구한다(기울기 밉). 그래서 정점 법선은 넘기지 않아도 되고, 필요하면 넣겠다. 필드 SRV·캐스케이드 길이는 include가 읽는 구조체 1개(버퍼 SRV 색인 하나)로 넘긴다.
3. **M resolve**: 저장 스트림은 정점 3개를 읽는다. 패치 스트림에서는 같은 include로 정점 3개를 다시 계산해야 한다(삼각형 id → 패치, i, j). 이 경로를 M과 V 중 누가 가질지 정해 달라.
4. **질문**: StreamRaster의 삼각형당·그룹당 비용을 [실측]으로 알려 달라. 규칙상 삼각형 수가 1~2 M이므로, 이 단가로 수면 행 비용이 정해진다.

## 4. W가 지금 하는 것

- 사분 트리 선택·절두체 컬링·LOD 모핑 계수 → 패치 목록(GPU 컴퓨트, 해상태의 σ(Δ) 표로 간격 결정).
- `OceanPatch.hlsli`(변위·이전 변위·법선·야코비안).
- V가 패치 스트림을 열기 전까지의 저장 삼각형 방출기. 같은 include로 패치를 삼각형으로 풀어 v1.60 스트림에 넣는다. 결과는 패치 스트림과 같은 기하이고 비용만 다르다(위 2의 트래픽).
- 시험: 패치 경계 틈 없음(이웃 LOD 정점 일치), 모핑 연속성, 간격 규칙(모든 패치에서 3σ(Δ) ≤ 0.5 px), CPU 참조와 같은 패치 집합.
