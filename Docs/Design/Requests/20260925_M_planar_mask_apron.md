# 요청: 평면 반사 뷰 마스크에 1픽셀 테두리(에이프런) (M 트랙 → R, 2026-09-25)

## 왜

v1.22 계약(`ViewDesc::planarMask`, `planarTileMask`)에서 평면 뷰는 거울 픽셀만 그린다. 마스크 0인 픽셀은 V가 `VIS_NONE`으로 두고, 거울 픽셀이 없는 타일은 M·S가 셰이딩하지 않는다.

M의 가장자리(E) 처리는 픽셀의 3×3 이웃을 본다.
- 검출(`EdgeDetect.hlsl`): 이웃과 표면이 다르면 가장자리다.
- 합성(`EdgeComposite.hlsl`): 이웃 삼각형들의 정확 면적으로 픽셀 정사각형을 나누고, 각 그룹 대표 픽셀의 복사를 섞는다.

거울 영역의 경계에 있는 거울 픽셀의 이웃 중 일부는 마스크 0이다. 그 이웃에는 반사된 장면의 표면이 있어야 하지만, 지금은 두 경우 모두 틀린 값이 된다.
1. **같은 타일 안의 마스크 0 픽셀**: vis가 `VIS_NONE`이라 M은 하늘로 본다. 거울 픽셀의 삼각형이 픽셀을 다 덮지 않으면 남은 면적이 하늘 복사를 받는다. 실제로는 V가 그리지 않은 반사 기하가 그 자리를 채워야 한다. 오차 상한은 경계 픽셀에서 덮이지 않은 면적 비율이다.
2. **거울 픽셀이 없는 이웃 타일**: 아무도 셰이딩하지 않는다. M 작업 트리는 이런 이웃을 "뷰 밖"으로 취급한다. 검출과 합성이 같은 규칙을 쓰므로, 쓰지 않은 복사를 읽는 일은 없다. 그래도 경계 픽셀의 남은 면적은 가장 먼 그룹이 가져가므로, 1과 같은 종류의 오차가 남는다.

R은 거울 픽셀만 읽으므로, 이 오차는 반사의 거울 경계에 그대로 나타난다.

## 원하는 변경 (R)

- **`planarMask` = 거울 픽셀을 3×3으로 팽창한 집합.**
  - 값 1 = 거울 픽셀(R이 읽음), 2 = 에이프런(그리고 셰이딩하지만 R은 읽지 않음), 0 = 건너뜀.
  - V·S·M은 0이 아닌 값을 모두 그린다. 지금 계약도 "0 아님 = 그림"이라 V·S는 바꿀 것이 없다.
- **`planarTileMask`** = 팽창된 마스크 기준, 즉 에이프런 픽셀이 있는 타일도 0이 아니다.
- R의 resolve는 값 1만 읽는다. 지금 "0 아님"으로 읽는다면 `== 1`로 바꾼다.

## 효과

- 거울 픽셀의 3×3 이웃은 모두 V가 그린 실제 반사 표면이 된다. 따라서 가장자리 검출과 합성이 직접 뷰와 같은 정확도(면적 정확, 겹침 ≤ 1/32)를 가진다.
- 비용 [예상]: 에이프런 픽셀 수 ≈ 거울 영역 둘레(픽셀). 창 하나(200×300 px)면 둘레 1,000 px로, 거울 픽셀 60,000의 1.7 %다. 픽셀당 비용이 거울 픽셀과 같으므로 C_planar에 +2 % 수준이다.
- M 쪽 변경: 없음. 에이프런 픽셀의 합성은 R이 읽지 않으므로 결과에 영향이 없다. 에이프런 바깥 이웃은 이미 "뷰 밖" 규칙으로 처리된다.

## 대안과 기각 이유

- M이 경계 거울 픽셀의 남은 면적을 거울 픽셀 자신의 복사로 채우는 방법: 반사 기하의 실제 경계를 지우므로 정확하지 않다(회피성 구현).
- R이 경계 픽셀을 광선으로 다시 추적하는 방법: 경계 픽셀마다 광선 1개(2.5 ns)가 들고, 합성 규칙이 직접 뷰와 달라진다.

## 결과 (코어, 2026-09-25, INTERFACES v1.28)

- `ViewDesc::planarMask` 값의 뜻(1 거울, 2 에이프런, 0 건너뜀)과 `planarTileMask`가 팽창된 마스크 기준이라는 점을 `Frame.h` 주석과 INTERFACES에 적었다.
- V는 바꿀 것이 없다. 컬링 마스크(`PlanarMask.hlsl`, 64 px)와 깊이 채움(`PlanarFill.ps`)이 이미 "0 아님"으로 판정한다. 에이프런 픽셀은 거울 픽셀과 똑같이 그려진다.
