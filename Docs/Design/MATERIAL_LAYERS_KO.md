# 재질 v2 설계: clearcoat와 박막 간섭 (코어, 2026-09-25)

I 요청 `Requests/20260925_I_material_layers.md`에 대한 설계다. 새 기능의 규칙(REBUILD_PLAN 13절)에 따라 **비용식과 품질 정의를 먼저** 적는다. 구현은 이 문서를 C·M·R이 확인한 뒤 코어(데이터·모델 권위 C++·HLSL 미러) → M(셰이딩)·R(hit·반사)·C(기준) 순으로 한다. 수치는 모두 [예상]이고 구현 뒤 실측으로 바꾼다.

**개정 (C 측정 9545fee, `Results/C/MaterialLayers/REPORT_KO.md`)**: 처음의 1.1 합성식은 반사 에너지를 12~72 % 과대평가했다. 생략한 코팅-기저 내부 반사는 "작은 손실"이 아니었다. 전반사로 갇힌 빛이 기저로 돌아가 흡수되는 항이었다. 기저 lobe의 굴절도 무시했다(각분포 L1 0.2~0.9). 그래서 품질 기준을 통과할 수 없어 1.1을 물리에서 다시 유도했다(아래). 박막은 C의 비교로 방법 (a)를 채택하고 약점 셋을 고친다(1.2). 재질 수치 기준을 새로 정했다(3절). 새 식은 C가 같은 도구로 측정한 뒤 확정한다.

## 1. 모델 정의 (INTERFACES 8.1 v2 초안)

재질 모델은 "정의"다. 실시간(M·R)과 기준 경로추적기(C)가 같은 식을 구현하므로 둘의 차이는 구현 오차뿐이다. 정의가 물리적 참값과 다른 부분은 3절에 따로 적고 측정한다.

### 1.1 Clearcoat (개정: 물리 유도, C 측정 대상 R1)
- 필드: 덮임 `clearcoat` c ∈ [0, 1], 코팅 지각 거칠기 `clearcoatRoughness` r_c. 코팅은 굴절률 η = 1.5 유전체이고, 두께 0, 흡수 없음(색 코팅은 나중 층), α_c = max(r_c², 1e-4). c는 덮인 면적 비율이다: **f = (1 − c) · f_base + c · f_layer**. 처음 정의는 c로 코팅 lobe만 줄였는데, 그러면 c < 1에서 물리적인 대응이 없다.
- **f_layer = f_c + f_1 + f_ms** (각 항은 RGB):
  - **코팅 반사 f_c**: GGX(α_c)의 D·G2와 **정확한 유전체 Fresnel** F_d(v·h; η)이다(Schlick는 60°에서 −19 % [실측 C]). 미세면 다중 산란의 반사 몫을 더한다. 방향 반사 알베도 R_c(μ) = E_c(μ, r_c)는 표다.
  - **투과** T(μ) = 1 − R_c(μ)이다. 흡수가 없으므로 들어가지 않은 에너지는 모두 반사된다.
  - **굴절 방향** ω′: 거시 법선에 대한 매끈한 굴절이다. μ′ = sqrt(1 − (1 − μ²)/η²), 방위각은 같다.
  - **첫 통과** f_1 = T(μ_i) · T(μ_o) · f_base(ω′_i, ω′_o; α′_b) / η², α′_b² = α_b² + ½ (1 − 1/η)² α_c².
    - 1/η²는 매질 안팎의 복사휘도 변환이다. 굴절 방향에서 평가하므로 입체각 압축이 들어간다. 밖에서 보면 기저 lobe가 약 η배 넓어진다.
    - α′_b는 거친 코팅을 두 번 지날 때의 방향 퍼짐이다. 소각 근사로, 한 번 지날 때마다 (η − 1)·σ_c만큼 퍼진다.
  - **내부 되튐** f_ms = T(μ_i) · [a(ω′_i) − e(ω′_i)] · ρ̄ / (1 − ρ̄ K) · T(μ_o) / (π η²):
    - a는 기저의 방향 알베도(스펙큘러 f0·A + B + 확산 몫)이다.
    - e는 그중 첫 반사 뒤 코팅 밖으로 바로 나가는 몫이다. 확산은 ρ(1 − K)이고, 스펙큘러는 f0·A_x(μ′, r_b) + B_x(μ′, r_b) 표다. a − e가 코팅 안쪽 면(전반사 포함)에 되돌려진 에너지다.
    - ρ̄는 기저의 반구 평균 알베도(확산 ρ, 스펙큘러 f0·Ā + B̄)이다.
    - K(r_c)는 코팅 안쪽의 확산 반사율이다(전반사 포함, 매끈하면 η 1.5에서 0.596).
    - 되돌려진 빛은 기저와 코팅 사이를 오가며 매번 ρ̄를 곱하고 (1 − K)만큼 빠져나간다. 금속·도료 기저가 어두워지고 채도가 오르는 "젖은" 외관이 이 항이다.
  - 박막이 있으면 f_base 스펙큘러의 F는 1.2의 F′이다. 표 항(a, e, ρ̄)의 f0 자리에는 F′(v·h = 1)을 쓴다.
- **정확한 조건**: 매끈한 코팅(α_c → 0)과 람베르트 기저에서는 f_1 + f_ms = T_i T_o ρ / (π η² (1 − ρK))다. 이 식은 이 경우의 정확한 해다(되튐의 각분포도 람베르트). 근사는 둘이고 C가 잰다. (1) 스펙큘러 기저의 되튐 각분포를 람베르트로 둔다. (2) 거친 코팅의 퍼짐을 α′_b 한 식으로 둔다.
- **표**(η = 1.5 고정, 오프라인에서 C의 물리 모델과 같은 적분으로 만든다):
  - E_c(μ, r_c) 32×32: 정확 Fresnel GGX 반사, 미세면 다중 산란 포함.
  - K(r_c) 32.
  - A_x·B_x(μ′, r_b) 32×32 두 장: 기저 스펙큘러 중 탈출 원뿔 안으로 나가는 몫.
  - Ā·B̄(r_b) 32: 기존 (A, B) 표의 코사인 가중 평균.
  - 합 약 12 KB, L1 상주.
- **태양 원반과 간접**:
  - f_c는 M의 태양 원반 스펙큘러를 그대로 쓴다. f_1의 기저 스펙큘러는 굴절 방향에서 같은 원반 함수를 쓰고, 원반 각반경은 굴절로 사상한다(내부 반경 ≈ 반경·μ_i/(η μ′_i)).
  - 간접(R의 반사, M의 면광원)에서 기저 lobe는 바깥 거울 방향이 그대로다. 외부 등가 거칠기는 α_eq ≈ η·α′_b(소각)다. R의 K/G/M 분류와 캐시 조회는 α_eq를 쓴다. C가 이 등가를 lobe 폭으로 확인한다.
- 처음 정의(f = f_c + T_c T_c f_base, Schlick, 굴절·되튐 없음)는 C 측정의 비교 기준으로만 남긴다.

### 1.2 박막 간섭
- 필드: 막 두께 `thinFilmThickness` d(nm, 0 = 없음), 막 굴절률 `thinFilmIor` η_f, 덮임 `thinFilmCoverage` w ∈ [0, 1], 기판 복소 굴절률 `substrateIor` η_s와 `substrateExtinction` κ_s. η_s와 κ_s는 **float3**(R, G, B 대표 파장별)다. 금속 기판(금 η ≈ (0.18, 0.42, 1.37), κ ≈ (3.4, 2.4, 1.8))의 색이 여기서 나오기 때문이다(I 검토). 데이터 월드는 세 채널이 같다(1.5, 2).
  - **저장하는 값은 채널별 맞춤 n·κ다**(C 측정): 650/550/450 nm 점 표본은 막이 없어도 분광 금 대비 ΔE 6.3이다. 같은 RGB 경로를 거친 반사율이 분광 반사율과 맞도록 각도 전체에서 맞춘 n·κ를 쓰면 금 0.8, 구리 0.1이다.
  - 금의 빨강처럼 R ≈ 0.95에서 (n, κ)가 퇴화하는 채널은 수직 입사만이 아니라 각도별 R(μ) 전체로 맞춘다.
  - 금속 프리셋(금, 구리, 은, 알루미늄, 철)의 맞춤값은 C가 표로 낸다. 코어가 `scene::model`의 프리셋으로 싣는다.
- 기저 스펙큘러의 Fresnel F를 F' = w · F_airy(v·h; η_f, d, η_s, κ_s) + (1 − w) · F_schlick(f0, v·h)로 바꾼다.
- **F_airy 방법 (C 측정으로 채택)**: Belcour & Barla 2017, 즉 Airy 세기 급수의 간섭항을 XYZ 감도의 가우시안 푸리에 근사로 분광 적분한다. 평균 ΔE76이 0.6~1.7로, 이전 엔진의 3대역 평균(2.1~6.2)보다 3~4배 정확하다 [실측 C]. 논문 코드를 그대로 옮기지 않고 방법만 따른다. 세 곳을 고친다.
  1. 계면 계수는 **정확한 복소 Fresnel**이다. 복소 굴절률 규약은 n + iκ 하나로 통일하고, 위상도 같은 규약으로 쓴다(논문 코드는 도체 위상에서 n(1 + iκ)와 섞는다). 색 변환은 XYZ → 선형 Rec.709, 광원 E 백색 균형이다(논문 코드는 CIE 1931 RGB 행렬).
  2. **급수 절단 제거**: m ≤ 3 항을 가우시안 감쇠와 함께 더한다. m ≥ 4 나머지는 Airy 분모의 닫힌 기하 급수에 m = 4의 감쇠를 곱해 더한다. 감쇠는 m에 대해 단조라 이 꼬리가 상한 쪽 근사다. 스침각·임계각 근처에서 절단 때문에 났던 최대 ΔE 30~88을 없애는 것이 목적이다.
  3. **전반사 안의 막(막 η_f < 바깥 매질 η)**: 복소 cos(q)로 Airy를 평가해 에바네센트 결합을 그린다. R = 1로 자르던 오차(|ΔRGB| 최대 0.5~1.0 [실측 C])가 없어진다.
- **비교 후보 (c)**: 가시 대역을 N칸으로 나누고 칸마다 Airy 반사율을 칸 평균(파수 위 포아송 핵 적분, 두꺼운 막의 비간섭 극한 포함)으로 구한다. 이것을 칸의 CMF 적분으로 가중해 XYZ를 만든다(N = 8, 16, 32). 이전 엔진 방식(b)의 오차는 3칸이 CMF의 음·양 엽을 무시한 데서 왔다. (c)는 N이 커질수록 분광 적분 자체로 수렴한다. 비용은 칸당 약 60 FLOP다.
- C가 (a) 개정판과 (c)를 같은 격자로 잰다. 3절 기준을 통과하는 것 중 비용이 낮은 쪽이 정의다. 표는 없다.
- 다중 산란 보정의 f0 자리에 F'(v·h = 1)을 쓴다(정의).
- 코팅이 있으면 막은 기저 위, 코팅 아래에 있다. 막의 바깥 매질 굴절률은 코팅이 있으면 1.5, 없으면 1이다.

### 1.4 Sheen (천·벨벳, 렌더 A, 2026-09-27)
- 필드: `sheenColor` C(선형 RGB, [0, 1], 0 = 없음), `sheenRoughness` r_sh ∈ [0.1, 1]. Standard 클래스 전용이고, 한 재질에 층 종류는 하나다(sheen이나 clearcoat). 검증(`validate`)이 강제한다. `.unxscene` 확장 블록 "SHEN"은 sheen이 있을 때만 쓴다(없는 파일은 그대로).
- **정의**: n·v, n·l > 0에서 f = f_sh + f_s · (1 − max(C) · E_sh(n·v, r_sh))이다.
  - f_sh = C · D(h) · G2(v, l) / (4 n·v n·l)
  - D = (2 + 1/α)(1 − (n·h)²)^(1/(2α)) / 2π(Charlie, Estevez & Kulla 2017), α = r_sh²
  - **G2 = 1 / (1 + Λ(v) + Λ(l)), Λ(ω) = A(n·ω)/n·ω − 1, A(μ) = ∫ D(m) max(0, ω·m) dm**: D 자체에서 유도한 Smith 가림이다. 투영 면적 A는 방위각 적분이 닫힌 식이라 1차원 적분 표가 된다.
  - **처음 후보(Neubelt V, 맞춤 없는 식)는 기각했다**: 알베도가 스침각·낮은 r에서 4.0까지 커졌다 [실측 CPU 시험]. 유도한 G2는 알베도가 1 이하이고, 시험 최대값은 0.9991이다 [실측].
  - 기저 배율 (1 − max(C) E_sh(n·v))는 시선 쪽에만 있다(Imageworks 알베도 배율). 그래서 모든 조명 적분(면광원, 간접)에서 적분 밖으로 나와 **정확하다**. 에너지는 E_sh + (1 − E_sh) B ≤ 1(B = 기저 알베도)이다. 시험 항등식 오차는 0.0002다 [실측].
- **표**: `scene::model::sheenTable()`은 A와 E_sh를 차례로 담는다. 각각 64열(√μ 등간격) × 32행(√((r − 0.1)/0.9) 등간격)이고 쌍선형이다. 합계 4096 float = 16 KB다. 간격을 이렇게 둔 이유: E_sh는 낮은 r의 스침각에서 가파르다. 32 × 32 선형 간격에서는 보간 오차가 18 %였다 [실측]. E_sh는 미세면 법선 h 영역에서 적분한다. dl = 4 v·h dh를 쓰면 D가 (cos θ_h, φ)에서 매끄럽다. 결정적 중점 적분이다.
- **태양**(`modelSheenSun` = C++ `sheenSunRule`): 원반(반지름 ρ = 0.2725°)에서 f_sh·max(0, n·l)의 평균이다.
  - 원반 전체가 지평선 위: c ± ρ/√2 · (u, w) 네 점 평균(원반 위 2차까지 정확).
  - 지평선에 걸침(|n·l| < k ρ): 보이는 원 조각을 Gauss–Legendre로 적분한다. φ 4점(t = ρ sin φ로 조각 가장자리의 제곱근을 흡수) × 가로 3점이다. 명암 경계 띠에서만 돈다.
  - 지평선 아래: 0.
  - 원반 중심 1점은 고도 2°에서 1.3 % 틀렸다. 곱 규칙(4점 f 평균 × 정확한 원반 평균 코사인)은 스침각 1/n·l 변화 때문에 9.6 %였다. 둘 다 기각했다.
  - 조밀 원반 평균(128 × 256) 대비 [실측 CPU]: 값이 최대 sheen의 5 % 이상인 곳은 상대 2.9e-3(지평선 걸침), 그 밖은 |오차|/최대 1.3e-3(역반사 스침: 반벡터가 원반 안에서 크게 돈다).
  - GPU 미러 대비 C++ [실측 하드웨어]: lobe 7.7e-6, E_sh 6.0e-8, 규칙 2.5e-6.
- **단계 2 결과 [실측 하드웨어]**: 셰이드 클래스 Sheen(5), ShadeOpaque LAYERED=2. 태양·점광원·간접이 들어갔고, 면광원은 기저만 keepS를 곱한다(sheen lobe는 단계 3 LTC). 대체 커널은 변형별로 클래스 마스크를 두고 돈다. 장면 시험(천 구, 태양): 8,406 픽셀이 keepS × 기저 + C × 태양 규칙과 1.45e-5로 맞는다. 명암 경계 28 픽셀은 G-buffer 16비트 법선에 민감해 프로브가 맡는다.
- **점광원**: 정의 그대로다.
- **면광원(단계 3)**: Charlie·G2·cos에 맞춘 LTC 표(이 lobe 전용, 알베도는 E_sh 표로 정규화)를 쓴다. 맞춤 오차는 GGX 스펙큘러의 LTC와 같은 부류의 근사이고, 시험에서 다각형 구적 대비로 잰다.
- **면광원 연구 결과(2026-09-27, `unx_test_shading_ltcfit --sheen --refine N --polygon-check`, Results/M/sheen_ltc_*.log) [실측 CPU]:**
  - 단일 LTC(Heitz 맞춤, 64 × 32, 이웃 재시작 2회): 정규화 lobe의 L1 평균 0.258, 최악 1.66(GGX 표는 0.088). 재시작으로 거의 줄지 않으므로 맞춤 실패가 아니라 모양 한계다(스침 시선 0.29~0.44).
  - 사각 면광원 48개/칸(방향 8, 반각 5·15·40°, 회전 2) 에너지 가중 오차: 평균 13.9 %, 704칸 중 682칸이 3 % 초과. 기각.
  - 한 방향의 정확한 lobe/LTC 비 보정: 광원 중심 37 %, 형태 인자 방향 17 %로 더 나쁘다. 기각.
  - (3) 입체각 구적(정확 lobe) [실측 CPU, Results/M/sheen_quad·sheen_tri·sheen_cv]: 사각형 전체의 Urena 매핑 + Gauss–Legendre는 6×6에서도 평균 5.1 %(266칸 > 3 %)다. sheen lobe가 지평선 쪽에서 최대라 에너지가 지평선에 걸친 광원에 몰리고, 거기서 피적분 함수가 꺾이기 때문이다. **지평선(z ≥ 0)으로 먼저 자르고** 볼록 다각형(≤ 5점)을 구면 삼각형으로 부채꼴 분할해 Arvo 면적 보존 매핑 + GL로 적분하면 2×2 8.0 %, 3×3 3.3 %, 4×4 1.5 %(91칸 > 3 %), **6×6 0.21 %(최악 6.9 %, 10칸 > 3 %)**다. LTC 제어 변량은 더 나쁘다(6×6 2.4 %).
  - **채택 방향(초기화 뒤 구현):** 지평선 절단 구면 삼각형 구적. 차수는 광원 입체각 Ω와 r_sh로 정하는 구조적 표(작은 광원 2×2, 넓은 광원·낮은 r 6×6)로 하고, 표는 크기별 오차 측정으로 정한다. 비용 [예상]: 광원 1개·sheen 픽셀 1개당 ≤ 3 삼각형 × n² × (lobe 약 50 + Arvo 약 40 ALU). 6×6이면 약 10k ALU, 4K 전 화면 sheen에 광원 1개면 약 2 ms이고, 2×2면 그 1/9다. 원판·구·관은 절단 뒤 곡선 경계라 모양별 매개변수화가 필요하다(구: 원뿔 균일, 원판·관: 평면 극좌표). 그때까지 sheen 면광원은 기저만 keepS로 그린다(알려진 결함 유지).
- **간접(단계 2)**: sheen 간접 = C · E_sh(n·v) · (근접 가림을 곱한 조도)/π다. 입사 복사휘도가 반구에서 균일하면 정확하다. 오차는 lobe(스침·역반사 쪽)와 코사인 가중의 모양 차이에 입사광의 비균일도를 곱한 것이다. C 기준 경로추적기의 하늘 구 렌더로 3절 ΔE 기준을 확인한다. 기저 간접은 배율만 곱하므로 정확하다.
- **발자국 대역제한**: α_sh'² = α_sh² + 발자국 분산이다(기저·코팅과 같은 규칙, 3절 4). 재질 워드 비트 24~31을 코팅 거칠기와 같이 쓴다(한 재질에 층 종류는 하나).
- **반사 광선 hit(R)**: R의 hit 셰이딩은 지금 기저만 한다. sheen hit은 R 요청 항목이다.
- **비용 [예상]**: A_s = sheen 픽셀 비율, P = 8.3 M(4K).
  - 태양: 4 × (D pow 1 + A 조회 2 + 산술 약 30) ≈ 150 ALU.
  - 점광원 L개: L × 약 40 ALU.
  - 면광원 L_a개: L_a × LTC 적분 1회(약 300 ALU).
  - 간접: E_sh 조회 1 + 곱 몇 개.
  - 표 16 KB는 L1 상주다.
  - 셰이딩 커널은 조회 지연에 묶이므로(2절) A_s = 0.2, L = 4, L_a = 0에서 추가분은 0.05 ms 미만으로 본다.
  - 층 없는 픽셀은 0이다(별도 셰이드 클래스, DXIL 한도 때문에 코팅과 다른 변형).
- **단계**:
  1. 정의, 표, CPU 시험, 장면 데이터. `unx_test_scene_sheen`: 표 대 독립 추정(Fibonacci 4 M 방향) 2 % 또는 0.002, E_sh ∈ [0, 1], 에너지 항등식, 상반성, 태양 4점 규칙, 블록 왕복, 검증.
  2. GPU 층 레코드, 셰이드 클래스, ShadeOpaque(태양·점광원·간접), resolve 거칠기, 하드웨어에서 C++ 대조.
  3. 면광원 LTC, coverage 조각(CoverageShade), C# `UnxMaterialDesc`.

### 1.3 데이터 (검토 반영)
- `scene::Material`: `clearcoat`, `clearcoatRoughness`, `thinFilmThickness`, `thinFilmIor`, `thinFilmCoverage`, `float3 substrateIor`, `float3 substrateExtinction`. 기본값은 층 없음(c = 0, d = 0)이다. `.unxscene` v2로 올리고 v1 파일은 기본값으로 읽는다.
- **층 레코드를 따로 둔다**: `gpu::Material`(80 B, 모든 픽셀이 읽는 뜨거운 레코드)은 그대로 둔다. 층 매개변수는 별도 `StructuredBuffer<GpuMaterialLayers>`(64 B: clearcoat, r_c, d, η_f, w, η_s float3, κ_s float3, 예비 1)에 담는다. `classFlags`의 비트 16~31이 그 레코드 번호다(층 재질 65535개까지). 비트 8~15의 플래그에 `MaterialClearcoat`, `MaterialThinFilm`을 둔다. `FrameConstants` 끝에 `materialLayers` SRV 줄(uint4)을 붙인다(528 → 544 B, 뒤에 붙이므로 기존 필드 위치는 불변).
  - 이유: 층 없는 재질은 레코드·대역폭이 v1과 같다. 나중의 층(sheen, 이방성, 디테일 색·법선, 유전체 위 막; 재구축 계획 13.1)은 층 레코드만 늘리면 되고 뜨거운 레코드는 건드리지 않는다.
- 셰이딩 클래스: M은 층 재질을 별도 셰이드 클래스로 둔다. 타일 분류가 `classFlags` 비트를 보고 층 재질이 있는 타일만 층 커널로 디스패치한다. 그래서 층 없는 픽셀의 레지스터·점유율·비용은 v1과 정확히 같다(M 결정, 인터페이스 변경 없음).
- I의 ABI(`UnxMaterialDesc`)는 같은 필드를 I가 추가한다.

## 2. 비용식 [예상]

셰이딩 예산(설계 2.11)에서 층은 **층을 가진 픽셀에만** 비용이 생긴다. A_c = 코팅 픽셀 비율, A_f = 박막 픽셀 비율(4K P = 8.3 M).

| 항 | 식 | 전체 화면(A = 1)일 때 | 비고 |
|---|---|---|---|
| 코팅 lobe 직접광(태양 + 해석 광원 L개) | 태양 원반 영역 함수 1회 + 면광원마다 LTC 적분 1회(약 300 ALU) + D·V·F | M 추정: A = 0.2, L = 4에서 층 추가분 합계 0.1 ms 미만 | FLOP 병목 아님(셰이딩 커널은 S·R 조회 지연에 묶임; 4080 약 49 TFLOPS) |
| 코팅 에너지 표 조회 | A_c · P · (1 + L) × (E_c, A_x·B_x 쌍선형) + 재질당 K·Ā·B̄ | 작음 | 표 약 12 KB, L1 상주. 굴절 방향 계산은 방향당 sqrt 1회 |
| **코팅 lobe 간접(반사)** | A_c · P · C_refl(r_c) | R 비용에 따라 다름 | **가장 큰 항**, 아래 |
| 박막 Airy 합 | A_f · P · (1 + L) · Airy 평가 | 위 합계에 포함 | 표 없음(ALU만) |
| 층 없는 픽셀 | 0 | 0 | 별도 셰이드 클래스(1.3) |

- **코팅의 간접 스펙큘러가 설계의 핵심 항이다.** 코팅 lobe(r_c 0.12)는 기저 lobe(r 0.3)보다 날카롭다. 그래서 R의 반사 경로 분류(K/G/M, 설계 2.6)에서 코팅 픽셀은 코팅 lobe로 분류한다. 기저 lobe는 두 가지 중 비용식으로 고른다. (a) 같은 광선의 hit를 기저 lobe로 다시 가중한다(r_base가 r_c보다 넓으면 좁은 lobe의 표본은 넓은 lobe를 편향 없이 대신하지 못하므로 추가 표본 필요). (b) GI 캐시의 광택 조회(G 경로)로 한다. R이 이 분기의 비용식을 확정한다(R 확인 요청).
- 데이터 월드(동적 상자·캐릭터가 재질 1, 화면 약 10~30 %)에서 A_c ≈ A_f ≈ 0.2라 하면, 직접광·박막 ≈ 0.14 ms이고 반사 추가분은 R 몫이다.

### 2.1 코팅 간접 반사 (R 검토 반영)
- 두 lobe를 반사 분류 규칙(설계 2.6 K/G/M)으로 **각자** 분류한다. 좁은 코팅 lobe의 표본을 넓은 기저 lobe로 재가중하는 방법은 쓰지 않는다(좁은 lobe는 넓은 lobe의 꼬리를 덮지 못해 분산이 유계가 아니다). 기저 lobe의 G 경로는 이미 캐시 제어변수 추정량이다.
- 코팅 픽셀의 `view.reflection` = 코팅 lobe의 입사 복사휘도. 기저 lobe는 θ_narrow(r_base, NoV) ≥ 22°이면 K(M이 캐시 조회, 광선 0)이고, 아니면 G/M이다. 기저가 G/M인 코팅 픽셀이 있으면 반사 출력이 둘 필요하다: `ViewResources::reflectionBase`(RGBA16F, 코팅 픽셀만, R 요청 예정).
- R의 비용식 [예상]: C_layer = A_c·P·[f_M,c·C_ray + f_G,c·4·C_ray/s_c²] + A_c·P·[f_G,b·4·C_ray/s_b²], C_ray ≈ 0.72~1 ns(hit 셰이딩 포함).
  **A_c = 0.2에서 코팅이 모두 M이면 1.2~1.7 ms로 반사 예산(0.41 ms)을 넘는다. 이 항은 예산에 맞게 다시 설계해야 한다.**
- **재설계 후보(품질 불변, 측정으로 결정)**: 분류 기준을 lobe 폭만이 아니라 **최종 복사휘도의 오차**로 둔다. 코팅은 굴절률 1.5 유전체라 반사 에너지 R_c(μ)가 수직 입사에서 약 4 %, 스침각에서만 커진다. 같은 입사 복사휘도 오차가 최종 픽셀에서는 R_c배로 작아진다. 그래서 K/G/M 경계를 "lobe 폭 × 그 lobe의 에너지 가중"으로 잡으면, 코팅 lobe의 대부분이 G(격자 간격 s_c, 광선 4/s_c²)나 K로 가고, 최종 오차 기준(설계 3절 반사 행)은 그대로 지켜진다. 스침각 코팅(R_c가 큰 곳)만 M에 남는다. R이 이 기준의 비용을 도시·데이터 월드에서 재고, 오차 기준을 지키는지 기준 영상으로 확인한다.
  - R 보완: 최종 오차 ≈ R_c(μ) × |L_true − L_cache|이고 뒤 항은 입사 복사휘도의 대비에 달렸다(비친 태양·밝은 창은 1e4배). 그래서 오차 추정에 캐시의 국소 대비(밉 사이 차이 또는 같은 방향 이웃의 분산)를 넣고, 추정 오차가 설계 3절 반사 허용치 이하일 때만 K/G로 내린다. 이 기준은 v1 유전체 기저 스펙큘러(f0 0.04)에도 같이 적용되므로 설계 2.6 분류 전체의 변경이다. R이 v1으로 먼저 전후(모드 비율, 반사 비용, 기준 영상 대비 relMSE·FLIP·허용치 초과 비율)를 품질 키로 비교한다.
- 평면 코팅면(바닥·유리)은 평면 반사 카메라가 코팅 lobe를 가져간다(비용식 선택, 이미 구현).

## 3. 품질 정의

- **점 평가는 정의 그대로**: 태양(원반 중심에서 T_c)과 점광원은 1절을 그대로 계산한다. M 테스트가 C++ `evaluate`와 HLSL 미러를 float 반올림 이내로 대조한다(v1과 같은 방식).
- **적분이 필요한 곳의 추가 가정(M 검토, 각각 측정해서 기록)**:
  1. 코팅 투과 T_c(μ_i)는 입사 방향 적분 안에 있어 조도·LTC와 정확히 분리되지 않는다. 면광원은 광원 쪽 로브 평균 방향, 간접 확산은 T_c의 코사인 가중 반구 평균, 간접 스펙큘러는 거울 방향으로 대표 평가한다. 오차는 적분 영역 안에서 T_c가 변하는 폭이다.
  2. 박막과 분할 합: (A, B) 분할은 Schlick F에서만 정확하다. 면광원·간접처럼 로브 적분이 필요한 곳에서는 F_airy를 대표 반벡터(v·h = NoV)에서 평가해 E를 곱한다. 거친 표면일수록 오차가 크다.
  3. **코팅 법선 = G-buffer의 셰이딩 법선**(노멀맵 적용, 정의). 코팅에 별도 법선(기하 법선, 코팅 노멀맵)을 쓰면 화면 버퍼가 4 B 늘어나므로 v2에는 넣지 않는다.
  4. **코팅 거칠기도 대역제한한다**: α_c'² = α_c² + 발자국 분산(곡률 + 노멀맵). 기저 α와 같은 규칙이다(v1, 설계 2.2). 없으면 먼 거리에서 반짝인다. M은 재질 워드의 남는 8비트에 α_c'를 담는다(인터페이스 변경 없음).
- **재질 수치 기준 (신설, 개정)**: 정의(1절 식)와 물리 모델(C의 위치 없는 몬테카를로 층 모델, 분광 Airy)의 차이다. 매개변수 격자 전체에서 다음을 모두 만족해야 한다. 격자는 r_c, 기저 종류(확산·도료·금속·검은 광택), r_b, θ 0~89°, 막 두께 0~2000 nm, 막·기판 굴절률이다.
  - 방향 알베도: 상대 오차 ≤ 2 %(또는 절대 ≤ 0.005).
  - 출사 각분포: L1 ≤ 0.05.
  - 렌더 색: 백색로와 태양·하늘 구 렌더에서 ΔE76 평균 ≤ 1.0, P99 ≤ 2.3(JND).
  - 통과하지 못하는 항은 기준을 낮추지 않고 정의를 다시 설계한다. 표를 물리 모델에 맞춰 만드는 방식도 후보다.
- **측정할 근사(C)**:
  1. Clearcoat R1(1.1): 스펙큘러 기저의 되튐 각분포를 람베르트로 둔 것, α′_b 퍼짐 식, 등가 거칠기 α_eq. 처음 정의 대비 개선을 같은 표(알베도·L1)로 낸다.
  2. 박막(1.2): (a) 개정판(정확 복소 Fresnel, 닫힌 꼬리, 복소 q)과 (c) N칸(8·16·32)을 평균·P99·최대 ΔE로 낸다. 금속은 맞춤 n·κ로 잰다.
  3. 코팅 + 박막 결합: 코팅 아래 막(바깥 η 1.5)에 1.1과 1.2를 함께 적용한 결과다.
- **기준 경로추적기(C)**: 1절 정의를 그대로 구현한다. 재질 표본 추출은 lobe 선택 확률을 코팅 R_c(μ_o), 기저 스펙큘러, 확산의 에너지 비로 둔다(분산만 달라지고 기댓값은 같다).

## 4. 순서와 영향

1. C·M·R이 1~3절을 확인한다. 특히 R은 2절의 코팅 간접 분기 비용식, C는 3절의 측정 방법이다. **개정 뒤: C가 3절 "측정할 근사"를 먼저 재고, 기준을 통과한 식으로 구현한다.**
