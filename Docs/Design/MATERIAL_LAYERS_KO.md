# 재질 v2 설계: clearcoat와 박막 간섭 (코어, 2026-09-25)

I 요청 `Requests/20260925_I_material_layers.md`에 대한 설계다. 새 기능의 규칙(REBUILD_PLAN 13절)에 따라 **비용식과 품질 정의를 먼저** 적는다. 구현은 이 문서를 C·M·R이 확인한 뒤 코어(데이터·모델 권위 C++·HLSL 미러) → M(셰이딩)·R(hit·반사)·C(기준) 순으로 한다. 수치는 모두 [예상]이고 구현 뒤 실측으로 바꾼다.

## 1. 모델 정의 (INTERFACES 8.1 v2 초안)

재질 모델은 "정의"다. 실시간(M·R)과 기준 경로추적기(C)가 같은 식을 구현하므로 둘의 차이는 구현 오차뿐이다. 정의가 물리적 참값과 다른 부분은 3절에 따로 적고 측정한다.

### 1.1 Clearcoat
- 필드: 세기 `clearcoat` c ∈ [0, 1], 코팅 지각 거칠기 `clearcoatRoughness` r_c. 코팅은 굴절률 1.5 유전체(f0_c = 0.04), α_c = max(r_c², 1e-4).
- 코팅 lobe: f_c = c · D(α_c) V(α_c) F_schlick(f0_c, v·h) · (1 + f0_c (1/E(μ_o, r_c) − 1)). 기저와 같은 D·V·F 함수와 같은 E 표(다중 산란 보정)를 쓴다.
- 코팅의 방향별 반사 에너지: R_c(μ) = c · (f0_c A(μ, r_c) + B(μ, r_c)) · (1 + f0_c (1/E(μ, r_c) − 1)). A, B는 스펙큘러 방향 알베도 분할 표(R 요청 `20260925_R_hit_shading.md` 1번: `scene::model::specularAlbedoTable()`, 32×32, A + B = E)다.
- 합성: f = f_c + T_c(μ_o) T_c(μ_i) · f_base, T_c(μ) = 1 − R_c(μ). f_base는 v1(또는 1.2의 박막 적용) 그대로다. 코팅은 기저 lobe의 방향을 굴절시키지 않고, 코팅 아래와 기저 사이의 내부 반사는 넣지 않는다(3절).
- 태양 원반: 코팅 lobe도 M의 태양 원반 스펙큘러(점 평가/원반 구적/좁은 로브 비율)를 같은 조건으로 쓴다.

### 1.2 박막 간섭
- 필드: 막 두께 `thinFilmThickness` d(nm, 0 = 없음), 막 굴절률 `thinFilmIor` η_f, 덮임 `thinFilmCoverage` w ∈ [0, 1], 기판 복소 굴절률 `substrateIor` η_s와 `substrateExtinction` κ_s(스칼라; 데이터 월드: 1.5, 2).
- 기저 스펙큘러의 Fresnel F를 F' = w · F_airy(v·h; η_f, d, η_s, κ_s) + (1 − w) · F_schlick(f0, v·h)로 바꾼다. F_airy는 Belcour & Barla 2017의 Airy 합이다. 분광 적분은 논문의 가우시안 감도 근사(XYZ → 선형 sRGB)로 RGB에서 닫힌 식으로 계산한다. 표는 없다.
- 다중 산란 보정의 f0 자리에 F'(v·h = 1)을 쓴다(정의).
- 코팅이 있으면 막은 기저 위, 코팅 아래에 있다. 막의 바깥 매질 굴절률은 코팅이 있으면 1.5, 없으면 1이다.

### 1.3 데이터
- `scene::Material`: 필드 7개(`clearcoat`, `clearcoatRoughness`, `thinFilmThickness`, `thinFilmIor`, `thinFilmCoverage`, `substrateIor`, `substrateExtinction`). 기본값은 층 없음(c = 0, d = 0)이다. `.unxscene` v2로 올리고 v1 파일은 기본값으로 읽는다.
- `gpu::Material` 80 B → **112 B**(float 7개 + 예비 1). 재질 수가 적어 메모리 영향이 없고, 반정밀도로 묶지 않아 정의를 그대로 싣는다. `classFlags`에 `MaterialClearcoat`, `MaterialThinFilm` 비트를 둔다. 커널이 이 비트로 분기하므로 층 없는 재질의 비용은 v1과 같다.
- I의 ABI(`UnxMaterialDesc`)는 같은 필드를 I가 추가한다.

## 2. 비용식 [예상]

셰이딩 예산(설계 2.11)에서 층은 **층을 가진 픽셀에만** 비용이 생긴다. A_c = 코팅 픽셀 비율, A_f = 박막 픽셀 비율(4K P = 8.3 M).

| 항 | 식 | 전체 화면(A = 1)일 때 | 비고 |
|---|---|---|---|
| 코팅 lobe 직접광(태양 + 해석 광원 L개) | A_c · P · (1 + L) · 90 FLOP / 20 TFLOP/s | L = 4일 때 0.19 ms | D·V·F + 보정; 태양은 원반 3영역 함수 한 번 더 |
| 코팅 에너지 표 조회 | A_c · P · 2 × (A,B,E 쌍선형) | 0.03 ms | 표 8 KB, L1 상주 |
| **코팅 lobe 간접(반사)** | A_c · P · C_refl(r_c) | R 비용에 따라 다름 | **가장 큰 항**, 아래 |
| 박막 Airy 합 | A_f · P · (1 + L) · 250 FLOP / 20 TFLOP/s | L = 4일 때 0.52 ms | 표 없음(ALU만) |

- **코팅의 간접 스펙큘러가 설계의 핵심 항이다.** 코팅 lobe(r_c 0.12)는 기저 lobe(r 0.3)보다 날카롭다. 그래서 R의 반사 경로 분류(K/G/M, 설계 2.6)에서 코팅 픽셀은 코팅 lobe로 분류한다. 기저 lobe는 두 가지 중 비용식으로 고른다. (a) 같은 광선의 hit를 기저 lobe로 다시 가중한다(r_base가 r_c보다 넓으면 좁은 lobe의 표본은 넓은 lobe를 편향 없이 대신하지 못하므로 추가 표본 필요). (b) GI 캐시의 광택 조회(G 경로)로 한다. R이 이 분기의 비용식을 확정한다(R 확인 요청).
- 데이터 월드(동적 상자·캐릭터가 재질 1, 화면 약 10~30 %)에서 A_c ≈ A_f ≈ 0.2라 하면, 직접광·박막 ≈ 0.14 ms이고 반사 추가분은 R 몫이다.

## 3. 품질 정의

- **실시간 = 정의**: 층의 모든 식은 1절 그대로다. 실시간 쪽 추가 오차는 v1과 같은 항목뿐이다. 표 쌍선형(32×32), 태양 원반 3영역 함수의 조건, 반사 경로의 분류 조건이 그것이고, 층마다 따로 늘지 않는다. M 테스트가 C++ `evaluate`와 HLSL 미러를 float 반올림 이내로 대조한다(v1과 같은 방식).
- **정의와 물리의 차이(모델 한계, 측정해서 기록)**:
  1. 코팅-기저 사이 내부 반사 생략: f0_c = 0.04일 때 잃는 에너지가 수직 입사에서 약 0.2 %, 스침각에서 수 %다. C가 한 번 몬테카를로 층 모델(위치 없는 무작위 보행)로 구해 정의 대비 차이를 표로 남긴다.
  2. 코팅의 굴절 무시(기저 lobe 방향 불변): 코팅 아래 기저 lobe는 굴절로 약간 좁아진다. 거칠기 등가 변환은 넣지 않는다(정의 단순성). 1과 같은 측정에 포함한다.
  3. 박막의 RGB 가우시안 감도 근사: 분광 적분 대비 오차를 C가 두께 0~2000 nm, 각도 0~89°에서 표로 남긴다. 논문 보고는 수 % 이내다 [예상; 측정으로 확정].
- **기준 경로추적기(C)**: 1절 정의를 그대로 구현한다. 재질 표본 추출은 lobe 선택 확률을 코팅 R_c(μ_o), 기저 스펙큘러, 확산의 에너지 비로 둔다(분산만 달라지고 기댓값은 같다).

## 4. 순서와 영향

1. C·M·R이 1~3절을 확인한다. 특히 R은 2절의 코팅 간접 분기 비용식, C는 3절의 측정 방법이다.
2. 코어: `scene::Material` 필드, `.unxscene` v2, `gpu::Material` 112 B, `MaterialModel.h/.cpp`(권위 C++) + `MaterialModel.hlsli` 미러, `specularAlbedoTable`(R 요청과 공유), INTERFACES 8.1 v2와 6.3 크기.
3. M: 셰이딩 커널(분기 비트, 태양 원반 함수 재사용), R: hit 셰이딩·반사 분류, C: 기준, I: ABI.
4. 데이터 월드 측정은 층이 들어가기 전까지 "재질 1은 기저 층만" 차이를 함께 적는다(I의 현재 처리).
