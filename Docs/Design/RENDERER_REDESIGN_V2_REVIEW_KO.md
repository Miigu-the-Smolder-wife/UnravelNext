# 재설계 V2 판정 (조정 세션, 2026-09-30 저녁)

대상은 [RENDERER_REDESIGN_V2_KO.md](RENDERER_REDESIGN_V2_KO.md)(cfbacdf)다. 기준은 [지시서](REDESIGN_BRIEF_20260929_KO.md) 0절과 7절이다. 설계 문서의 모든 비용은 [예상]이다. 판정도 설계에 대한 것이고, 합격은 구현 뒤 실측으로만 한다.

## 결론

- **0절(움직이는 중에도 매 프레임 깨끗): 설계로서 통과.**
  - 잡음 원천 다섯 개(N1~N5)를 항별로 나눴다. 그리고 "매 프레임 공간 재구성, 짧은 시간 보조"의 재구성 층으로 바꾼다.
  - 첫 프레임 기준을 시간 누적 없이 만족해야 한다는 조건을 구현 조건으로 적었다.
  - 품질 정의(Q-A~Q-E)가 조정 세션 기준선(`Results/Local/Baseline-5e31d8c`)과 같은 단위다.
  - 구현 순서 P1 → P2 → P3이 이 요구를 먼저 푼다.
- **7절 "1440p 합계가 여유를 두고 3 ms 안": 불통과.**
  - 구조 변경만으로는 기차 4.42 / 욕탕 4.32 ms다.
  - 3 ms 근처(3.11 / 3.09)는 결정 항목 D-2(내부 배율 1/2)를 켜야 나온다. D-1·D-4까지 더해도 욕탕은 3.07이라 여유가 없다.
  - GPU 시뮬레이션을 더한 4K 전체 프레임은 6.3~6.5 ms로 6.06을 넘는다.
- **7절 "최악의 경우에도 예산 안": 불통과.**
  - 해 무제한 속도·달리는 기차의 VSM 전량 dirty(V1 가정 입력으로 욕탕 1440p +1.1 ms)가 예산 밖 별도 행이다.
  - 반사 최악(전 화면 G 간격 1, 순회 2.2 ms)도 "기록만"으로 남았다.
  - 설계가 이 셋을 4.3절에 숨기지 않고 적은 점은 맞다.

## 권고

1. **P0 → P3 구현을 지금 시작한다(클라우드 Opus).** 사용자 최우선 요구(움직임)를 푸는 단계이고, 예산이 닫히는지와 독립이다. P0의 실측 기준선과 MB-B(표본 재구성 CPU 모델)가 첫 판단이다.
2. **비용 재설계 V2.1을 설계 세션에 다시 맡긴다.** 목표 셋:
   - 내부 2/3에서 1440p ≤ 3 ms를 여유를 두고 닫는다. 남은 1.3~1.4 ms를 D-2가 아닌 정보 표현 재설계로 줄인다. 후보는 2.5절 후속 항목, 반사 hit 조명, GI trace, 셰이딩이다.
   - VSM 전량 dirty와 반사 최악을 예산 안에 넣는다.
   - 4K 전체 6.06 ms를 닫는다.
3. **사용자 결정:**
   - D-1(반사 hit 국소광을 결정적으로)은 설계가 권고했다. 반짝임 잡음을 원천에서 없애고 비용도 준다.
   - D-2(내부 1/2)는 P3과 MB-B로 "보이는 것이 같다"가 실측된 뒤에 정한다.
   - D-3·D-5는 설계도 권고하지 않았다.
   - D-4·D-6·D-7은 해당 단계에서 정한다.

## V2.1 판정 (4ee5741, 2026-09-30 밤)

## V2.2 판정 (f6b8876, 2026-10-01 새벽)

배경: P0·P1 실측(fe7f9b4)이 V2·V2.1의 가정을 깼다. 조정 세션이 설계 세션에 V2.2를 맡겼다. 품질 레버가 아니라 "표에 못 미치면 다시 설계한다"는 기존 원칙에 따른 것이다.

- **설계로서 통과(P1′, P2).**
  - 잡음의 뿌리를 텍셀 정의(원뿔 안 점 하나를 표본)로 좁혔다. 해법은 기준 추적기와 같은 광원 모델로 원뿔 평균을 구하는 것이다.
  - 에너지 시험(GiAnalytic 8번, ±0.5 %)이 붙었다. 표본 수는 불변이고 비용은 +0.05 ms다.
  - 편향 없는 수렴 조건(S/B 분리, 가중치는 n의 함수만, 데이터 없음 = 부모값)과 고정점 시험 3개가 구체적이다.
  - 조명 변화는 광원 그룹별 L1 SH로 첫 바운스를 1프레임에 갱신한다(+64 MB).
- **사용자 확인이 필요한 것.**
  - **첫 프레임 목표 8 %**(V2.1은 3 %). 근거는 원뿔 평균 뒤 부모–자식 차 p95 4.7 % [실측]다. 저주파 편향이고 고주파 초과 0, 화소 σ ≤ 2 %를 함께 요구한다. 품질 정의의 변경이므로 사용자가 본다. 최종 판정은 눈이다.
  - **D-15**: 느린 이동의 "같다"를 4×4 초표본 원래 해상도 기준으로 판정한다. 1 spp 원래 해상도는 스스로 에일리어싱하기 때문이다. 거부하면 D-2와 업스케일 결정으로 돌아간다.
  - **D-16**: 모든 불을 끌 때의 relight 계약. 첫 바운스는 1프레임이고, 다중 반사는 ρ^갱신 곡선을 따른다. 광선 하한상 8프레임 ≤ 3 %는 불가능하다.
  - D-12, D-13, D-14: 원뿔 평균 뒤에도 표에 못 미칠 때만 잰다.
- **예산.** 11.6 표는 승인된 D-8(−0.20 / −0.25)을 기본에 넣지 않았다. 넣으면 2/3에서 약 3.61 / 3.73, D-2 열에서 약 2.62 / 2.78 [예상]이다. 3 ms 결론(D-2 또는 표본 규칙 결정)은 같다.
- **진행.**
  - P1′-a(원뿔 평균) → P1′-b(수렴 조건: 구현 세션이 하는 편향 수정과 같은 일) → P1′-c(광원별 SH) → P2를 지금 구현한다.
  - P3′는 CPU 모델(SampleListModel.py) 통과와 D-15 결정 뒤에 한다.
