## 1. Clearcoat: 내부 반사·굴절 생략 (3절 1·2항)

**기준(물리 모델):** 위치 없는 몬테카를로 층 모델. 윗면은 거친 유전체(GGX α_c, n = 1.5, 정확한 Fresnel, 굴절, 전반사, 단일 산란
미세면: VNDF 표본 + G1 가중), 아랫면은 v1 기저 BRDF를 매질 안 방향으로 평가, 두께 0, 흡수 없음. 광원에서 에너지를 추적해
출사 방향 18 × 18 칸에 모은다. **정의:** 설계 1.1 그대로(c = 1; A·B는 정확 적분, E는 정의의 표). 칸당 에너지 400만 표본.
**검증:** 검은 기저(코팅만)에서 수직 입사 알베도 정의 0.0400 / 물리 0.0400, 60°에서 물리 0.089 = 정확 Fresnel(0.0894).

**판정:** 설계의 예상("내부 반사 생략 손실이 수직 약 0.2 %, 스침각 수 %")은 틀렸다. 생략된 것은 손실이 아니라
**전반사로 갇힌 빛이 기저로 돌아가 다시 흡수되는 효과**(코팅의 어두워짐·채도 증가, "젖은" 외관)다. 정의는 반사 에너지를
확산·도료 기저에서 12~36 %, 광택·금속 기저의 스침각에서 최대 40~72 % **과대평가**한다. 굴절(기저 lobe 방향 불변 가정)의
각분포 오차도 크다(L1 0.2~0.9, 금속 기저가 가장 크다). 이 크기는 어떤 FLIP 임계에서도 통과할 수 없는 수준이므로
**1.1의 합성식은 품질 기준을 만족하지 못한다.** 코팅만의 차이(Schlick f0 0.04 vs 정확 Fresnel: 60°에서 −19 %)도 별도 항목으로 남는다.

**제안(측정 대상, 채택 전 같은 도구로 검증):** 정의에 (1) 코팅 아래 내부 반사로 인한 기저 에너지 보정 ρ' = ρ (1 − K)/(1 − ρ K)
(K = 코팅의 매질 쪽 확산 반사율, n = 1.5에서 ≈ 0.6, 거칠기 의존 표), (2) 기저 평가 방향을 굴절된 방향으로(입체각 압축 포함),
(3) 코팅 Fresnel을 정확 유전체식(또는 그 표)으로. 코어가 식을 정하면 이 도구에 후보로 넣어 같은 표를 다시 낸다.

## 2. 박막 간섭: RGB 근사 vs 분광 계산 (3절 3항 + I 요청)

**기준:** 파장마다(360~830 nm, 1 nm) 편광 평균 정확 Airy 반사율(복소 Fresnel, 기판 복소 굴절률), CIE 1931 2°, 광원 E,
선형 Rec.709(E에서 백색 균형: 일정 반사율 R → RGB (R,R,R)). 격자: 입사 0~89°(1°) × 두께 0~2000 nm(5 nm).
**(a) 설계안:** Belcour & Barla 2017 — Airy 세기 급수(m ≤ 3)의 각 간섭항을 XYZ 감도의 가우시안 푸리에 근사로 적분, 계면 계수는
정확한 복소 Fresnel, XYZ → Rec.709/E. (논문 코드는 CIE 1931 RGB 행렬을 쓰고 도체 위상에서 n(1+ik)와 n+ik 규약을 섞는다 —
그대로 옮기면 틀리므로 방법만 따랐다.) **(b) 이전 엔진:** 세 대역(580~700 / 490~580 / 400~490 nm) 역파장 평균 정확 Airy.
**금속:** 기준은 Johnson & Christy 분광 n·k, RGB 방법은 650/550/450 nm 점 표본 또는 맞춤 삼중값(아래).

**판정:**
- **(a)가 (b)보다 전반적으로 3~4배 정확하다**(평균 ΔE 0.6~1.7 vs 2.1~6.2, P99 2~8 vs 7~27). (b)의 대역 평균은 CMF의 음·양
  엽을 무시하므로 간섭 색이 체계적으로 틀린다. (b)는 막이 없거나(d = 0) 굴절률이 맞을 때만 정확하다.
- **(a)의 약점:** m ≤ 3 절단 — 계면 반사 진폭이 1에 가까운 스침각·임계각 근처에서 오차가 크다(예: 코팅 1.5/막 2.4/유전체
  기판 스침각 d → 0에서 최대 ΔE 88, 코팅 1.5/막 1.33의 임계각 바로 앞 d = 0에서 ΔE 30; 비율로는 격자의 1 % 미만).
  닫힌 형태의 무한 급수(Airy 분모)를 가우시안 적분과 함께 쓰면 절단이 사라진다 — 개선 후보.
- **금속은 간섭보다 기판 표현이 지배적이다:** 막이 없어도(d = 0) 650/550/450 nm 점 표본 n·k는 분광 금 대비 ΔE 6.3, 구리 1.8.
  채널별로 분광 반사율에 **맞춘** n·k(금 (0.15, 0.49, 1.49)/(12, 2.26, 1.76) — 빨강 채널은 R ≈ 0.95에서 n·k가 퇴화, 구리
  (0.26, 1.04, 1.30)/(3.20, 2.62, 2.34))로 바꾸면 d = 0 오차가 금 0.8, 구리 0.1로 줄고 막이 있을 때 (a)의 평균 ΔE가 금 1.5~3.0,
  구리 0.8~1.2가 된다. **기판 η·κ를 float3로 바꾸면 점 표본이 아니라 맞춤값을 저장해야 한다.**
- **전반사(막 굴절률 < 코팅 1.5, 임계각 밖):** 두 RGB 방법 모두 R = 1로 두며, 얇은 막을 통한 에바네센트 결합을 못 그린다
  (최대 |ΔRGB| 0.52~1.00). 정의가 막 n ≥ 바깥 매질 n을 요구하거나, 복소 q로 Airy를 평가해야 한다.
- 품질 기준: 설계에 재질 단위의 수치 기준이 아직 없다. 흔히 쓰는 ΔE76 ≈ 2.3(JND)을 기준으로 보면 (a)는 유전체·설계 기본 기판에서
  평균은 기준 안, P99는 기준의 1.4~3.5배, 금속은 맞춤 n·k일 때만 평균이 기준 근처다. (b)는 평균부터 기준을 넘는다.
