# 실내 간접광(GI) 품질 결함 — 목욕탕·기차 (렌더 B, 2026-09-27)

사용자 보고: 두 게임 실내에서 "노이즈가 엄청 심하고 품질이 별로". 장면은 게임 세션이 브리지 `SaveScene`으로 저장했다(`bath_bt0.unxscene`, `train_v0.unxscene`, 추적 안 함). 자동 노출이라 ev100이 NaN이어서 카메라 ev100만 6으로 바꾼 사본(`*_ev6.unxscene`)으로 엔진과 기준을 같은 단위로 비교했다.

도구: 엔진 `unx_gate_shadow_renderergate --capture`(선형 복사휘도 × 노출, 600프레임), 기준 `unx_reference render --spp 1024`(CPU, 960×540; 캐시 `Cache/Reference/{bath_bt0,train_v0}`), 비교 `gicmp.py`(1080p 이상은 2×2 평균으로 540p에 맞춤).

| 원인 | 증거 | 수정 |

| 다중 되튐 Jacobi 단계가 고정 8회였다. 그 뒤 32회 이력 평균이 옛(어두운) 반복값을 품어 수렴률이 갱신당 1 − α(1 − s) | ρ = 0.9 백색로(해석해 10π): 600프레임 −16.3 %, 계속 수렴 중 | Jacobi 길이를 항목의 되튐 몫 s로 정함: s^J ≤ 0.4 %(J는 Jacobi 단계 동안만 자라고 리셋까지 고정) |
| 되튐 칸(hit footprint × 4)이 방 크기라, 방 전체의 다중 반사가 칸 몇 개의 잡음을 공유 | 실행마다 욕탕 전체 밝기가 7~11 % 다름 | `gi.hit_cell_footprint_scale` 4 → 2: 1.7 % |

## 남은 것

- 목욕탕 벽·욕조 앞면 −15~19 %. 벽의 **직접광**도 기준의 0.86배(조명 갓 안 점광원의 국소 그림자, S)이고 간접광도 비슷하게 낮다. 바닥·천장은 ±2 % 이내.
- 기차 벽 패널·중앙 기둥의 흰 장식 무늬가 엔진에서만 보인다(수정 전후 같음): 룩 패스 재질이 기준과 다르게 보인다(렌더 A 영역). 타일 P95 700 %의 원인.
- 기차 바닥이 기준의 1.28~1.35배(수정 전 1.10), 드문 밝은 점. 햇빛을 hit에서 꺼도 같다.
- 이력 256의 움직이는 태양 지연은 재지 않았다(설계상 3σ를 넘으면 32로 줄어든다).
- city_block 캐시 용량 압박(위).

## 2차: 원형 경계·햇빛 누설 (S, 2026-09-27 저녁)

- 원인 [실측]: 반사 hit의 햇빛 조회(`shadowSunVisibilityAt`)가 굵은 층의 공기용 상주 페이지를 썼다. 그 페이지에는 직접 뷰의 이웃 전파(VsmPropagate: L+1..L+3의 3×3)가 없어, 추정기가 페이지 밖 탭에서 "캐스터 없음"을 읽었다. 닫힌 욕탕의 바닥 반사에 햇빛이 새어 화면의 22.5 %(그림자 광선만: 0.7 %). 직접 햇빛 자체는 0.3 %로 정상.
- 판별: 해 끔 → 원 경계·누설 0. 반사 hit를 그림자 광선만으로 → 0.7 %. 고운 층부터 찾기 → 2.4 %. 계약 검사(페이지 + L+1 3×3 상주) → 1.1 %.
- 수정: 층 L은 그 페이지와 L+1 3×3이 상주할 때만, 고운 층부터; 없으면 그림자 광선. 조회는 hit당 최대 4 × 10 페이지 표 적재(고정 상한).
- 결과(해 켬, 코트 원본, 600프레임): 목욕탕 편향 +25.1 → −1.8 %(1080p −2.0 %), 타일 오차 P95 166 → 17 %, 원형 경계 소멸(호스트 경로 원 안/밖 99/109 → 109/111). 기차 타일 P95 704 → 40 %, relMSE 8.85 → 0.07(벽 패널 흰 무늬도 이 누설), 편향 −10.6 %(1080p −5.2 %: 누설이 가리던 부족분).
- 비용 [실측, A/B/A/B, 경합 0, 300프레임 중앙값, 욕탕]: r.refl.shade 1440p 1.23 → 0.61 ms, 4K 2.15~2.37 → 0.92 ms; 반사 합계 1440p 2.03 → 1.42, 4K 3.54~3.77 → 2.31 ms.
- 시험: VsmTests, WaterShading, Pool, Translucent, LocalShadow, PlanarMirror 통과. ReflectionAnalytic은 GI hit 스펙큘러 뒤 기대값이 램버트 캐시라 비트 1024를 적용해 평균 1.002로 복귀, 어제부터의 최악 픽셀 항목만 실패.
- 남은 것: 햇빛 3 %가 GI 캐시 칸을 통해 벽을 넘어 샌다(굵은 칸이 바깥을 읽음). 흰 사각 점은 하네스·호스트 캡처 모두 수정 전에도 재현되지 않았다(앞서 "재현"은 지표가 줄눈을 센 오류) — 게임에서 새 스냅샷으로 확인.
